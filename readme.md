# Quran Bangla Verse Player

`Vibe Coded`
A minimalist web application for sequentially playing Quran verses with synchronized Bengali translation and Arabic audio recitation.


## Features

*   **Sequential Playback:** Listen to verses one after another.
*   **Synced Audio & Text:** Displays Bengali translation while playing Arabic audio (Mishary Alafasy).
*   **Surah Selection & Search:** Easily choose and find Surahs.
*   **Smooth Transitions:** Animated display updates between verses.
*   **Clean Interface:** Minimalist design using Tailwind CSS.

## Technology

*   **Frontend:** HTML, CSS (Tailwind), Vanilla JavaScript
*   **API:** [Al-Quran Cloud API](https://alquran.cloud/api)



## Usage

1.  Clone or download the project.
2.  Open the main HTML file in a web browser.
3.  Select a Surah and click "Play".
